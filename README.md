1. 🎨 바이브 코딩(Vibe Coding) 프레젠테이션
바이브 코딩의 개념과 특징을 소개하기 위해 제작한 웹 프레젠테이션 프로젝트입니다. HTML, CSS, JavaScript를 활용하여 구현하였으며, 별도의 설치 없이 웹 브라우저에서 실행할 수 있습니다.

📌 프로젝트 개요

생성형 AI와 LLM 기술이 빠르게 발전하면서 자연어를 활용한 새로운 개발 방식이 등장하고 있습니다. 본 프로젝트는 이러한 개발 트렌드 중 하나인 바이브 코딩을 주제로 하여 개념, 활용 사례, 장점 및 한계점을 발표 자료 형태로 정리한 웹 애플리케이션입니다.
총 15개의 슬라이드로 구성되어 있으며, 사용자가 원하는 내용을 쉽게 탐색할 수 있도록 다양한 인터랙션 기능을 적용하였습니다.

🎯 제작 목적

바이브 코딩의 개념 이해
AI 기반 소프트웨어 개발 방식 학습
생성형 AI 활용 사례 탐구
발표 자료 제작 및 웹 구현 역량 향상

2. 👨‍💻 개인 프로젝트
   
   
🎲 랜덤 이름 추첨기

사용자가 이름 목록을 입력하면 무작위 추첨을 진행할 수 있으며, 최대 3명까지 동시에 당첨자를 선정할 수 있습니다. 추첨 과정에는 카운트다운, 애니메이션 효과, 사운드 기능을 적용하여 재미를 더했으며, 당첨자 관리 및 추첨 이력 확인 기능을 통해 편리하게 결과를 관리할 수 있도록 구현하였습니다.

배포 링크 : https://name-lottery-program.netlify.app 


🌿 이화여자대학교 UI/SI 재구성

HTML과 CSS를 활용하여 이화여자대학교의 UI(University Identity) 시스템을 웹페이지 형태로 재구성한 프로젝트입니다.

심벌마크, 로고, 지정서체, 디지털 자산 및 브랜드 스토리를 하나의 웹페이지에 정리하여 이화여자대학교의 시각적 아이덴티티를 효과적으로 전달할 수 있도록 구현하였습니다.

배포 링크 : https://ewha-ui.netlify.app
